# 知时 · 注意力与健康

一款安静、克制的 Chrome / Edge 扩展：记录每个网站的使用时长，提供护眼与久坐提醒、网站限额。**所有数据仅保存在本机**，不上传任何服务器。

视觉体系移植自 [@paradox/ui](https://github.com/1parado/UI_UI)（shadcn 令牌体系、明暗双主题、图表五色板），遵循「quiet surface、最轻边框阴影、几乎无动效」的设计原则。

## 功能

| 功能 | 说明 |
| --- | --- |
| 使用时长统计 | 只统计「标签页活跃 + 浏览器在前台 + 系统非闲置」的时间；按域名聚合，事件驱动结算，每分钟落盘。展示精确到秒（42 秒 / 5 分 12 秒 / 2 小时 18 分） |
| 视频心跳 | 对白名单站点（默认 bilibili.com、youtube.com，可在网页右键开关），页面正在播放音视频时持续计时——全屏、画中画、后台窗口均有效，不受闲置判定影响。仪表盘里有实时心跳状态，可用于自查 |
| 图标角标 | 实时显示今日累计（如 `2.4h`），接近/超过每日目标时变色 |
| popup 实时秒表 | 显示当前站点的今日累计，每秒跳动 |
| 护眼提醒 | 20-20-20 法则，默认每 20 分钟；间隔可自定义 5–120 分钟；触发时段可设全天或时间段（支持跨零点）；人不在电脑前不打扰 |
| 久坐提醒 | 默认每 45 分钟（默认关闭）；间隔可自定义 10–240 分钟 |
| 网站限额 | 为指定域名设每日上限，超限后打开该网站跳转拦截页，次日自动恢复；可「放行 10 分钟」。支持**时段屏蔽**（如 23:00–08:00 直接拦截）。**在任意网页上右键 →「将 xx.com 加入网站限额」**，直达设置页并预填域名；添加第一条限额时自动打开总开关。列表支持**按名称搜索**和**条件筛选**（全部 / 启用中 / 已停用 / 今日已达） |
| 每日目标 | 设定每日总时长目标，弹窗进度环与角标颜色联动 |
| 仪表盘 | 今日/近 7 天统计、周柱状图、年度热力图、网站排行、全部设置与数据导出（CSV/JSON） |

健康提醒与网站限额均通过启用/禁用开关控制：popup 里有总开关，仪表盘里有逐项设置。

## 安装（加载已解压的扩展程序）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`browser-extension`）
4. 固定到工具栏即可使用

> 注意：从 popup 点「打开仪表盘」会在新标签页打开完整页面，不要依赖把仪表盘塞进弹窗——弹窗窗口会缩到内容宽度。

## 右键加限额

在任意网页空白处右键，菜单里会出现**「将 xx.com 加入网站限额」**（自动显示当前域名），点击后直接打开仪表盘的网站限额页：域名已填好，输入每日分钟数点「添加」即可。

## 计时口径

时间只在这三个条件同时满足时计入：

1. 标签页处于活跃状态（非后台标签）
2. 浏览器窗口处于前台（切去别的应用即暂停）
3. 系统非闲置（键鼠 60 秒无输入、锁屏均视为离开）

实现上是纯事件驱动：所有标签页/窗口/闲置事件与每分钟兜底闹钟汇入一次「结算 + 重估」，单次结算上限 90 秒，防止休眠唤醒后把离开时间一次记满。会话状态存放在 `chrome.storage.session`，service worker 被杀也能恢复。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `tabs` | 读取活跃标签页的 URL（只提取域名，不存完整网址与页面内容） |
| `storage` / `unlimitedStorage` | 本地保存统计与设置 |
| `idle` | 感知用户离开，暂停计时与提醒 |
| `alarms` | 每分钟结算兜底、健康提醒周期触发 |
| `notifications` | 护眼/久坐系统通知 |
| `contextMenus` | 页面右键菜单（加限额、视频心跳开关） |
| 内容脚本（全部站点） | 仅 `src/content/heartbeat.js`：检测音视频是否正在播放并上报心跳信号，不读取任何页面内容 |

不需要任何 host 权限；网站限额通过后台判定 + 标签页跳转实现。

## 目录结构

```
manifest.json            MV3 清单
icons/                   生成的时钟图标（16/32/48/128）
src/
  lib/pure.js            纯函数（域名提取、时长格式化、CSV、热力图分档），Node 可测
  lib/settings.js        设置默认值、读取、保存、限额增删改
  background/
    service-worker.js    后台入口：事件汇总与分发
    tracker.js           计时引擎（结算 + 重估 + 限额拦截判定）
    store.js             每日聚合存取（d:YYYY-MM-DD）、放行记录
    health.js            护眼/久坐闹钟与系统通知
    badge.js             角标文本与颜色
  pages/
    shared.css           设计令牌与基础组件（对齐 @paradox/ui）
    popup.html/css/js    弹窗：今日用量、排行、两个总开关
    dashboard.html/...   仪表盘：概览 / 网站限额 / 健康提醒 / 数据
    block.html/...       限额拦截页
scripts/
  make-icons.mjs         零依赖 PNG 图标生成器
  verify-cdp.mjs         端到端验证（CDP 驱动 Edge：灌数据 → 截图 → 心跳/限额链路检查）
  diag-hb.mjs            心跳链路诊断（注入/播放/登记逐环检查，需先启动本地视频页）
tests/pure.test.mjs      纯函数单元测试
verify/                  最近一次验证的截图
```

## 开发

```bash
node --test tests/pure.test.mjs   # 单元测试
node scripts/make-icons.mjs       # 重新生成图标
node scripts/verify-cdp.mjs       # 端到端验证（需本机 Edge）
```

改动后到扩展管理页点击「重新加载」即可生效。

仪表盘控制台里有 `window.__seedDemo()`，可灌入 140 天演示数据，用于开发预览。

## 已知限制

- 纯阅读（60 秒无键鼠输入且无音视频播放）会被视为闲置暂停计时；音视频播放场景已由视频心跳覆盖
- **扩展「重新加载」后，已打开的标签页不会自动获得新的内容脚本**——请刷新对应页面（如正在看的 B 站视频页），否则视频心跳不会生效
- 隐身窗口默认不统计（浏览器对扩展默认关闭隐身访问）
- service worker 休眠跨越闲置唤醒时，误差最多 90 秒（单次结算上限）
- 无头或锁定环境下一切计时与拦截自动暂停，属于设计行为
